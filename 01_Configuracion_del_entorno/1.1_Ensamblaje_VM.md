# 1.1. Descarga, ensamblaje e importación de la máquina virtual

## Objetivo

Descargar, ensamblar e importar la máquina virtual GNU/Linux Debian proporcionada por la Universidad de Palermo para desarrollar el Trabajo Práctico Integrador de Computación Aplicada.

## Descarga y organización de los archivos

Se ingresó a la plataforma Blackboard de la Universidad de Palermo y se descargaron los nueve archivos comprimidos correspondientes a la máquina virtual proporcionada por la cátedra.

Los archivos, denominados desde `TPVMCA.part01.rar` hasta `TPVMCA.part09.rar`, se organizaron en una carpeta denominada `TP_Computacion_Aplicada`.

**Figura 1.** Archivos comprimidos de la máquina virtual descargados y organizados.

![Captura 01.01](Capturas/Captura%2001.01.png)

## Extracción de la máquina virtual

Se utilizó WinRAR para extraer el contenido del archivo `TPVMCA.part01.rar`. El programa reconoció automáticamente las ocho partes restantes y permitió reconstruir el archivo original.

Como resultado, se obtuvo el archivo `TPVMCA.ova`, necesario para importar la máquina virtual en Oracle VirtualBox.

## Importación en Oracle VirtualBox

Se abrió Oracle VirtualBox y se seleccionó la opción **Archivo → Importar servicio virtualizado**.

Se indicó la ubicación del archivo `TPVMCA.ova` y se verificaron los parámetros originales de configuración:

| Parámetro | Configuración |
|---|---|
| Nombre | TPVMCA |
| Sistema operativo | Debian 11 (64 bits) |
| Procesadores | 2 CPU |
| Memoria RAM | 2048 MB |
| Formato del disco virtual | VDI |

Se conservaron los parámetros proporcionados por la cátedra y se confirmó la importación.

**Figura 2.** Parámetros de configuración de la máquina virtual en Oracle VirtualBox.

![Captura 01.02](Capturas/Captura%2001.02.png)


## Resultado y verificación

La máquina virtual `TPVMCA` se incorporó correctamente al administrador de Oracle VirtualBox, quedando disponible para iniciar las actividades de configuración del entorno.

Se verificó que la máquina apareciera en la lista de máquinas virtuales con estado **Apagada**.

**Figura 3.** Máquina virtual incorporada correctamente a Oracle VirtualBox.

## Creación de una instantánea inicial

Como medida preventiva, se creó una instantánea de la máquina virtual `TPVMCA` inmediatamente después de su importación en Oracle VirtualBox.

Esta operación permite conservar el estado inicial del entorno virtualizado y disponer de un punto de recuperación ante posibles errores durante las posteriores actividades de configuración y administración del sistema operativo.

La instantánea se denominó `00 - VM original importada`.

**Figura 4.** Instantánea inicial de la máquina virtual registrada en Oracle VirtualBox.

![Captura 01.04](Capturas/Captura%2001.04.png)

**Nota sobre la numeración de las instantáneas:** el árbol final no tiene una instantánea `01`. Durante el punto 1.2 se presionó por error **Ctrl derecho + T** (atajo de VirtualBox para sacar una instantánea) en lugar de **Ctrl derecho + E** (captura de pantalla), y se generaron cuatro instantáneas sin nombre. La primera, que conservaba el estado de la máquina recién importada, se renombró como `00 - VM original importada`; las otras tres se eliminaron. Eliminar una instantánea no borra los cambios hechos después: VirtualBox los fusiona con el estado siguiente.
