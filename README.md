## Descripción del proyecto

El presente trabajo práctico integrador consiste en la configuración y administración de un servidor GNU/Linux Debian, utilizando una máquina virtual proporcionada por la cátedra.

Las actividades comprenden la configuración del entorno, actualización del sistema operativo a Debian 12, instalación y administración de servicios, configuración de red, almacenamiento, automatización de copias de seguridad y preparación de los archivos requeridos para la entrega.
