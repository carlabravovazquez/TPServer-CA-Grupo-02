# 2.4. Base de datos MariaDB y carga de `db.sql`

## Objetivo

Instalar el motor de base de datos MariaDB y cargar el script `db.sql` del material de la cátedra, para que `index.php` muestre los datos de los alumnos. Comprobarlo desde la computadora física.

## Conceptos previos

MariaDB es un motor de base de datos relacional derivado de MySQL; en Debian reemplaza a MySQL y mantiene sus comandos (Niklas, 2020, p. 62). Corre como servicio, con su propio usuario de sistema `mysql` (Universidad de Palermo, s. f., *Administración de usuarios*, p. 2).

**Contenido de `db.sql`** (33 líneas, codificación UTF-8):

- `CREATE DATABASE ingenieria`: crea la base de datos;
- `CREATE USER 'lcars'@'%' IDENTIFIED BY 'NCC1701D'` y `GRANT ALL PRIVILEGES ON ingenieria.*`: crea el usuario que usa `index.php` y le da permisos sobre la base;
- tablas `alumnos`, `modulos` y `notas`, con 5 alumnos, 4 materias y 15 notas.

El usuario, la contraseña y el nombre de la base coinciden con los que usa `index.php` para conectarse.

`mysql (1) - the MariaDB command-line tool (mysql is now a symlink to mariadb)`: `mysql` es el cliente de línea de comandos de MariaDB (*Comandos*, p. 3, `whatis`). El cliente no figura en los apuntes; así se identificó.

```bash

```

El símbolo **`<`** hace que `mysql` lea sus órdenes desde el archivo en lugar del teclado (*Redireccionamiento y Pipes*, p. 2). No muestra nada: sin mensajes significa sin errores. `root` entra a MariaDB sin contraseña porque Debian autentica al usuario `root` de la base mediante el usuario del sistema que se conecta por el socket.

**Figura 6.** Carga del script.

![mysql <](Capturas/Captura%2002.69.png)

```bash
echo "SHOW DATABASES;" | mysql
echo "SELECT * FROM ingenieria.modulos;" | mysql
```

`echo` escribe el texto y el **pipe `|`** lo envía como entrada a `mysql`, que lo ejecuta (*Redireccionamiento y Pipes*, p. 3). Las comillas agrupan la orden SQL, que tiene espacios y termina en `;`. Resultados: aparece la base **`ingenieria`** (junto a las del sistema: `information_schema`, `mysql`, `performance_schema`, `sys`) y las 4 materias con los acentos correctos.

## Problemas encontrados y solución

Durante la instalación y la carga de la base no hubo problemas. Tampoco hubo inconvenientes con los acentos, porque el archivo `db.sql` está codificado en UTF-8 y MariaDB 10.11 de Debian 12 usa `utf8mb4` por defecto.

Sí se observó un problema después: al revisar el `history` en el punto 3, ya no figuraban las líneas 70 a 78 de este punto. Igual que en el punto 2.2, la máquina se apagó desde la ventana de VirtualBox y no con `shutdown -h now`, por lo que Bash no llegó a guardar el historial. Los cambios en el sistema sí quedaron aplicados (MariaDB y la base siguen funcionando en el punto 3), y la captura de la Figura 9 conserva el `history` completo, tomado antes del apagado.

## Resultado

MariaDB 10.11 quedó instalada y activa, con la base `ingenieria` cargada. La página `index.php` muestra la tabla de alumnos desde la computadora física.

**Instantánea de VirtualBox:** `06 - Punto 2.4 MariaDB`.
